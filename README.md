# QR Code Generator

A clean, super simple, and lightweight QR code generator built with Angular. Paste any link or text and instantly download the generated QR code image in high-resolution PNG format.

## Features

- ⚡ **Real-time Generation**: QR code updates dynamically as you type or paste your link.
- 💾 **Instant PNG Download**: Download your QR code image with one click.
- 📐 **Clean & Unified Layout**: Left-aligned header, perfectly matching widths across the input field, QR code frame, and download button.
- 🚀 **Built with Modern Angular**: Uses Angular Signals and standalone components.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/gonzagramaglia/qr.git
   cd qr
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Running the App

Start the development server:

```bash
npm start
```

Navigate to `http://localhost:4200/` in your browser.
